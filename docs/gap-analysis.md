# 정처기 실기 학습 자료 갭 분석 (2026-10-16 기준)

대상: `data/exams/*.json` 21회차 420문항(2020-1 ~ 2026-2), `data/concepts/*.json` 12과목 181토픽 2,064용어.
다음 시험: 2026년 3회 실기 2026-10-24 ~ 11-13 (D-8 ~ D-28). 출제기준은 2026년과 2027~2029년이 실기에서 동일(필기만 4과목 80문항으로 개정).

## 1. 한 줄 결론

**이 자료만으로 합격 가능하다. 단, (1) 코드 문제 8문항 중 최소 3문항을 잡을 수 있도록 10-programming.json에 C 연결 리스트·Java enum/제네릭·Python 컴프리헨션 패턴을 보강하고, (2) 비코드 12문항에서 9문항 이상을 확보하도록 아래 14개 용어 빈틈을 채우고, (3) 2026년 두 회차 복원본을 2차 출처와 대조한다는 조건에서다.** 비코드 문항의 94%(90/96)가 2024년 이후에도 이전 회차 키워드를 그대로 재사용하고 있어 기출 반복만으로 45~50점이 나오고, 코드 문항 64개 중 42개(66%)가 기존 패턴(상속·오버라이딩·슬라이싱·static·포인터 산술) 조합이어서 나머지 10~15점은 거기서 나온다.

**A1. OTP (일회용 비밀번호)** — 2025-3 #11
- 추가 위치: `09-security.json` > 토픽 "인증 (Authentication) 유형과 AAA"에 points·terms 추가 (또는 신규 토픽)

- summary: 한 번 쓰면 폐기되는 인증 비밀번호. 시간 동기(TOTP)·이벤트 동기(HOTP)·질의응답 방식이 있고 재전송 공격을 막는다.
- terms: OTP (One-Time Password) / TOTP (Time-based OTP, 시간 동기) / HOTP (HMAC-based OTP, 이벤트·카운터 동기) / 재전송 공격 (Replay Attack) / 챌린지-리스폰스 (Challenge-Response)

**A2. OAuth 2.0과 토큰 기반 인가** — 2025-3 #13

- terms: OAuth 2.0 / Access Token / Authorization Code Grant / Resource Owner · Client · Authorization Server · Resource Server / OpenID Connect (인증 계층)

**A5. TCP 연결 수준 공격 세부 (시퀀스 번호 추측·반열림 연결)** — 2025-1 #1, 2025-2 #19

- terms: TCP 시퀀스 번호 (Sequence Number) 예측 / 3-way 핸드셰이크 (SYN·SYN-ACK·ACK) / 반열림 연결 (Half-open Connection) / 백로그 큐 (Backlog Queue) / SYN Cookie (방어)

## 6. 사이트에 추가하면 합격에 직접 도움이 될 기능 (우선순위 순)

1. **실전 모의고사의 유형·연도 가중 추출.** 현재 `shuffle(Q).slice(0,20)`은 420문항 균등 추출이어서 코드 6.3문항·서술형 0.8문항·2020년 문항 19%가 나온다. 실제 분포(코드 8 · SQL 2 · 단답/빈칸 10, 서술 0, 2023년 이후 60% 이상)로 층화 추출하면 모의고사 점수가 실제 점수의 예측값이 된다. `index.html`의 random/mock 분기 한 곳만 바꾸면 된다.
2. **코드 문항 집중 모드: 언어 필터 + 패턴 묶음 + 개념 링크.** 과목별 기출 "프로그래밍 언어 활용" 안에서 C/Java/Python/SQL 탭, 그리고 keywords 기반 패턴(연결 리스트·상속/오버라이딩·static·슬라이싱·예외·포인터 산술) 묶음으로 같은 유형을 연속 풀이. 각 문항 하단에 10-programming 해당 토픽 링크. 40점짜리 영역을 패턴 단위로 반복하는 것이 코드 3→5문항으로 올리는 유일한 방법이다.
3. **개념 ↔ 기출 양방향 자동 링크와 빈출 순 정렬.** `build.py`에서 문항 keywords와 토픽 terms를 매칭해 `asked`를 자동 생성하고, 개념 목록을 "최근 3년 출제 횟수" 내림차순으로 정렬·표시(예: "디자인 패턴 — 14회차 출제, 최근 2026-2"). 암기카드도 같은 가중치로 출제 빈도 높은 용어가 먼저 나오게 한다. 03·05·06·12 과목이 자연스럽게 뒤로 밀린다.
